# Browser verification

Run `npm ci`, `npx playwright install chromium`, then `npm run test:e2e`. The suite starts a local Nuxt server at port 3187, or uses `E2E_BASE_URL` when provided. `CHROME_PATH` can select an installed Chromium executable; each run creates a fresh isolated browser context. It never connects to an existing browser or profile.

The desktop (1440×1000) and mobile (390×844) projects verify both locales and themes, all nine dock destinations, metadata, horizontal overflow, language changes without document reload, persisted theme, keyboard booking with an intercepted S/20 checkout conflict, and the separate accessible assistant panel with an editable draft before consent. Booking requests are intercepted; no payment, event, email or model invocation occurs. Medium pagination checks every reported page, with at least the ten entries in the verified snapshot. Screenshots, JSON results, traces on failure and the HTML report are written to ignored `reports/`.

Logo tests compare actual screenshot pixels after CSS/theme rendering. Transparent PNGs are measured against a second screenshot of their real chip with the image hidden. For opaque rectangles, a uniform intrinsic corner background is detected and used instead; background pixels never count as the logo. One-pixel erosion removes anti-aliasing edges. The 10th percentile of remaining solid foreground must be ≥3:1, meaning at least 90% meets the target. Every logo produces a screenshot and JSON measurements. `scripts/analyze-logos.mjs` classifies source luminance and chooses a chip; that source analysis is not a substitute for this rendered test.

`npm run audit -- https://oscarbahamonde.com/es` runs Lighthouse in a separate headless browser. The 2026-11-14 managed macOS attempt failed before navigation: Chromium's crashpad Mach bootstrap returned Permission denied (1100) and aborted. This is an environment launch failure, not a Lighthouse result. No numeric Lighthouse or rendered E2E success is claimed until the reports are produced in a compatible runtime.

## Vercel Sandbox fallback and screenshot corrections

Because macOS Chromium could not launch and GitHub Actions could not allocate a runner, verification moved to one ephemeral Ubuntu 26.04.1 / Node 24.22.3 Vercel Sandbox (1 vCPU, 2 GB). Chromium 159 / Playwright 1.65.1 was installed from the official package. The source was commit `6f3c38`, with the final audio/payment frontend files taken from `fd52d4` and the documented visual/test corrections. No production secrets were loaded. This runs a local production build, not the deployed domain.

All attempts are preserved, including failures: (1) Node 24 rejected the test JSON import without an import attribute; the test now reads JSON explicitly. (2) The fixed dock overlapped some locator boxes after `scrollIntoViewIfNeeded`; those measurements are invalidated. Each image is now centered in the viewport and five hit-tested points must be unobstructed before capturing. (3) With valid captures, only NETCOR failed: p10 was 1.54–1.58 against its intrinsic white backing. A measured CSS brightness/contrast filter improves legibility while retaining the official asset and color channels. (4) A shell-managed server child survived termination and prevented replacement (EADDRINUSE), so that interrupted attempt is invalidated; the final Node server is directly managed on a fresh port.

The mobile booking test now scrolls the booking card into view, triggering its existing lazy availability loader. This changes the test precondition, not the booking logic.

Final integrated result: **24/24 Playwright cases passed**, **112/112 rendered logo checks passed** across all eight variants, minimum p10 **3.8000:1** (Bluetab). NETCOR p10≥7.0380, Data&Analytics≥5.1742 and Valtx≥6.4760. The archive `docs/audit/after/playwright-artifacts.tar.xz` preserves all five attempts, 680 PNG captures (89 unique), final JSON, logs and source hashes; all 730 manifest file hashes were verified after download. Extract from the repository root with `tar -xf docs/audit/after/playwright-artifacts.tar.xz`. The sandbox and temporary evidence-only transport were stopped afterward. The archive demonstrates an isolated build, not production payment/audio/Turnstile.
