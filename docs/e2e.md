# Browser verification

Run `npm ci`, `npx playwright install chromium`, then `npm run test:e2e`. The suite starts a local Nuxt server at port 3187, or uses `E2E_BASE_URL` when provided. `CHROME_PATH` can select an installed Chromium executable; each run creates a fresh isolated browser context. It never connects to an existing browser or profile.

The desktop (1440×1000) and mobile (390×844) projects verify both locales and themes, all nine dock destinations, metadata, horizontal overflow, language changes without document reload, persisted theme, keyboard booking with an intercepted S/20 checkout conflict, and the separate accessible assistant panel with an editable draft before consent. Booking requests are intercepted; no payment, event, email or model invocation occurs. Medium pagination checks every reported page, with at least the ten entries in the verified snapshot. Screenshots, JSON results, traces on failure and the HTML report are written to ignored `reports/`.

Logo tests compare actual screenshot pixels after CSS/theme rendering. Transparent PNGs are measured against a second screenshot of their real chip with the image hidden. For opaque rectangles, a uniform intrinsic corner background is detected and used instead; background pixels never count as the logo. One-pixel erosion removes anti-aliasing edges. The 10th percentile of remaining solid foreground must be ≥3:1, meaning at least 90% meets the target. Every logo produces a screenshot and JSON measurements. `scripts/analyze-logos.mjs` classifies source luminance and chooses a chip; that source analysis is not a substitute for this rendered test.

`npm run audit -- https://oscarbahamonde.com/es` runs Lighthouse in a separate headless browser.
