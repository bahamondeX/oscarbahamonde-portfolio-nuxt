Se muestran junto al nombre de cada empresa, sin inferir cargos o fechas adicionales.

- DATA & ANALYTICS: el original cian sobre blanco no alcanza 3:1. Se conserva el PNG original y se presenta con filtro CSS monocromo de contraste (`grayscale(1) brightness(.65) contrast(3)`); el nombre permanece como texto semántico. La simulación de píxeles originales pasa p10=4.65:1; esto no sustituye la medición real de navegador.
- Valtx: reducción a 64 × 64 px generaba un primer decil de contraste de 2.87:1 por interpolación. Un filtro CSS conservador `contrast(1.25)` conserva el PNG y sus colores, y eleva el preflight a 3.43:1. Debe confirmarse con la captura real de navegador.
